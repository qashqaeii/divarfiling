درون‌ریزی مقاله از JSON

فایل JSON کامل را بارگذاری یا paste کنید — تصویر شاخص اختیاری است و بعداً اضافه می‌شود.

ساختار JSON

  • format_version — نسخه 1.0
  • options.publish — انتشار فوری
  • options.force_update — بازنویسی در صورت تکرار slug
  • article.slug_base — نامک URL
  • article.title — عنوان
  • article.excerpt — خلاصه (حداکثر ۳۰۰)
  • article.category — slug, name, description, order
  • article.tags — آرایه برچسب‌ها
  • article.content — HTML کامل مقاله
