    • کلید معتبر است — API کار می‌کند

    • مدل‌های :free ناپایدار — 429 و timeout شایع
    • کیفیت فارسی پایین‌تر از Gemini — rule_based اغلب بهتر از خروجی بد OR
    • پاسخ ممکن است در message.reasoning باشد نه content — parser هر دو را چک کند
    • max_tokens کافی بگذارید (حداقل ۴۰۰) تا reasoning-only خالی نماند

منطق quota.py:
  1. staff/superuser → بدون محدودیت
  2. بدون لایسنس → quota_exceeded (code=no_license)
  3. used_today >= daily_limit (10) → daily_limit
  4. tokens_used_today >= AI_DAILY_TOKEN_LIMIT → token_limit
  5. feature_used >= feature_max → feature_limit
  6. AI_GLOBAL_DAILY_CAP (350) → rule_based مستقیم + log
  7. cache hit → بدون کسر سهمیه

اتصال به کد موجود:
  from workspace.services.access import has_active_bot_license

۸. Provider Chain — جزئیات پیاده‌سازی

── providers/base.py ────────────────────────────────────────────────────────

@dataclass
class ProviderResult:
    text: str
    provider: str           # gemini | openrouter | rule_based
    model: str
    input_tokens: int | None
    output_tokens: int | None
    latency_ms: int
    is_fallback: bool

class AIProvider(Protocol):
    name: str
    def complete(self, *, system: str, user: str, json_mode: bool = False) -> ProviderResult: ...

class ProviderError(Exception):
    retryable: bool = True   # True → برو provider بعدی
