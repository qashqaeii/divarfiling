■ دستورالعمل کلی برای ChatGPT
───────────────────────────────────────────────────────────────────────────────
1. لحن: دوستانه، حرفه‌ای، محاوره‌ای — زبان مشاور املاک ایران، نه متن فنی خشک.

2. مخاطب:
   • مشاور مستقل که می‌خواهد از دیوار فایل جمع کند
   • مشاور میدانی که بیشتر با موبایل کار می‌کند
   • مدیر آژانس که بین ویندوز (حجم بالا) و موبایل (سرعت) تصمیم می‌گیرد

3. طول هر مقاله: ۳۵۰۰ تا ۵۵۰۰ کلمه (۱۸ تا ۲۸ دقیقه مطالعه)

4. ساختار HTML:
   - فقط HTML معتبر (بدون Markdown)
   - حداقل ۲ جدول مقایسه‌ای
   - حداقل ۱ باکس mk-blog-tip-box
   - حداقل ۳ سناریوی واقعی
   - FAQ با schema.org (حداقل ۵ سؤال)
   - CTA طبیعی، نه تبلیغاتی اغراق‌آمیز

5. نکات محصولی که حتماً رعایت شوند:
   • CRM میز کار رایگان است
   • استخراج/فایلینگ/تحلیل پیشرفته نیاز به لایسنس فعال دارد
   • یک لایسنس برای ویندوز و اندروید مشترک است
   • استخراج سنگین (>۱۰۰ آگهی، Excel حجیم، دانلود انبوه تصویر) → ویندوز
   • استخراج سبک محله‌ای و کار روزانه CRM → اندروید
   • استخراج ابری روی سرور از طریق اپ اندروید (بدون روشن بودن دائمی گوشی)
   • پرداخت و خرید لایسنس فقط از وب (divarfiling.ir/pricing/)
   • اپ اندروید جایگزین اپ دیوار نیست — ابزار CRM/فایلینگ مشاور است

6. لینک‌سازی: فقط URLهای بخش «مرجع لینک‌ها»

7. خروجی: JSON با schema divarfiling.blog.article-import

【 ربات ویندوز — Divar Filing Extractor 】
  • نصب روی Windows 10/11
  • استخراج خودکار از divar.ir
  • فیلتر: استان، شهر، محله، نوع معامله، زیردسته (آپارتمان، ویلا، دفتر...)
  • استخراج موازی / گروهی (Batch) چند منطقه
  • ادامه از آخرین نقطه (Resume)
  • Merge بدون تکرار در استخراج مجدد
  • فیلتر خودکار آگهی همخانه (اجاره مسکونی)
  • بیش از ۸۰ فیلد ساختاریافته
  • تشخیص نوع آگهی‌دهنده (شخصی/مشاور/بنگاه)
  • دانلود تصاویر آگهی
  • خروجی Excel / CSV / JSON
  • ساختار پوشه: output / استان / شهر / محله
  • پوشش ۳۱ استان
  • آپلود خودکار به میز کار وب
  • فعال‌سازی با لایسنس + شناسه سخت‌افزار (HWID)
  • رابط فارسی RTL، تم روشن/تاریک
  • تب‌ها: استخراج، نمایش، تحلیل، ابزارها

【 اپ اندروید — میزکار موبایل 】
  • Kotlin + Jetpack Compose
  • ورود با حساب میز کار
  • CRM کامل: مخاطب، معامله، ملک، امروز، یادآور، تقویم
  • فایلینگ: لیست آگهی، جستجو، فیلتر، نقشه، insights
  • اعلان Push (FCM): تطبیق ملک، یادآور، فایل جدید
  • Deep link به مخاطب/معامله/تطبیق
  • استخراج سبک روی گوشی (سقف لایسنس، مناسب کار میدانی)
  • استخراج ابری روی سرور (زمان‌بندی، بدون وابستگی به PC)
  • همگام‌سازی دوطرفه با سرور — سرور منبع حقیقت
  • قالب پیام، تیم (لینک به میز کار وب)، AI، پشتیبانی
  • دانلود: /shop/download/android/ یا کافه‌بازار
  • لایسنس مشترک با ویندوز
