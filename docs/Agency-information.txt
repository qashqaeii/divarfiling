قابلیت‌های موردنظر:

1. صندوق پیام داخلی ساده  [x]
- شبیه Inbox و بدون Real-time
- ارسال پیام خصوصی بین اعضای همان آژانس
- امکان پاسخ به پیام
- مدیر و مالک بتوانند برای همه اعضا یا نقش خاص پیام گروهی ارسال کنند
- وضعیت خوانده‌شده، خوانده‌نشده، آرشیو و ستاره‌دار
- امکان ضمیمه فایل با محدودیت حجم و نوع
- اعلان داخل پنل برای پیام جدید
- حذف خودکار پیام‌ها و فایل‌های قدیمی‌تر از ۳۰ روز
- بدون آنلاین بودن، تایپ‌کردن، Seen لحظه‌ای، تماس یا گروه‌های پیچیده

2. Activity Feed  [ ]
- نمایش رویدادهای مهم تیم به‌صورت خواندنی
- ثبت مخاطب، ملک، معامله، تماس، بازدید، تخصیص سرنخ، انتقال پرونده، تغییر نقش و رسیدن به هدف
- فیلتر بر اساس نوع رویداد، عضو و بازه زمانی
- بدون نیاز به Real-time؛ با Refresh یا Polling سبک

3. Announcement Board  [x]
- ثبت اطلاعیه توسط مالک یا مدیر
- تعیین عنوان، متن، فایل ضمیمه، سطح اهمیت، تاریخ انتشار و انقضا
- امکان سنجاق‌کردن اطلاعیه
- ارسال برای همه یا نقش خاص
- نمایش واضح اطلاعیه‌های خوانده‌نشده و مهم

4. تقویم تیمی  [ ]
- ثبت جلسه، بازدید، تعطیلی، جلسه فروش و رویداد داخلی
- امکان تعیین عضو یا اعضای مرتبط
- نمایش روزانه، هفتگی و ماهانه
- دسترسی ایجاد و ویرایش بر اساس نقش
- اتصال به تقویم شخصی فعلی بدون ایجاد داده تکراری

5. Leaderboard حرفه‌ای  [ ]
- رتبه‌بندی اعضا بر اساس تماس، بازدید، معامله بسته، نرخ تبدیل و کمیسیون
- بازه امروز، هفته، ماه، ۳۰ و ۹۰ روز
- نمایش سه نفر برتر و جایگاه هر عضو
- فرمول امتیاز قابل تنظیم از پنل مدیریت
- جلوگیری از ایجاد رقابت ناسالم یا نمایش اطلاعات محرمانه

6. KPI لحظه‌ای  [ ]
- تعداد تماس امروز
- بازدید امروز
- مخاطب جدید
- معامله فعال
- معامله بسته
- سرنخ بدون تخصیص
- پیگیری معوق
- کمیسیون دوره
- مقایسه با روز یا دوره قبل

7. Heatmap  [ ]
- نمایش ساعات و روزهای پرترافیک برای تماس، بازدید، ثبت مخاطب و معامله
- استفاده از داده‌های موجود و Queryهای تجمیعی
- بدون محاسبات سنگین در هر بار بارگذاری
- در صورت نیاز با Cache و Job دوره‌ای

8. Knowledge Base  [ ]
- راهنمای داخلی آژانس
- قوانین، فایل‌های حقوقی، قرارداد نمونه، دستورالعمل فروش و آموزش اعضا
- دسته‌بندی، جستجو، فایل ضمیمه و Pin
- دسترسی خواندن و ویرایش بر اساس نقش
- ثبت نسخه و تاریخ آخرین بروزرسانی

9. Dashboard TV Mode  [ ]
- صفحه تمام‌صفحه، فقط خواندنی و مناسب نمایش روی تلویزیون دفتر
- نمایش KPI امروز، اهداف، رتبه اعضا، آخرین اطلاعیه‌ها، سرنخ‌های جدید و معاملات
- Refresh خودکار سبک
- عدم نمایش اطلاعات حساس مانند شماره تلفن، جزئیات مشتری یا گفتگوهای خصوصی
- امکان انتخاب ویجت‌های قابل نمایش و تم روشن/تاریک

الزامات مهم:
- هیچ‌کدام از قابلیت‌های فعلی بخش آژانس نباید خراب یا مختل شوند.
- نقش‌ها و دسترسی‌های مالک، مدیر، مشاور و منشی حفظ شوند.
- داده‌های هر آژانس کاملاً از آژانس‌های دیگر جدا باشند.
- تمام Permissionها سمت Backend کنترل شوند.
- از Queryهای N+1 جلوگیری شود.
- برای لیست‌های بزرگ از Pagination استفاده شود.
- قابلیت‌ها ماژولار و قابل خاموش‌کردن با Feature Flag باشند.
- طراحی UI کاملاً RTL، مینیمال، حرفه‌ای، خلاقانه و هماهنگ با تم فعلی فایلینگ دیوار باشد.
- از ساخت یک پیام‌رسان زنده یا زیرساخت سنگین خودداری شود.
- برای Inbox، Activity Feed و TV Mode از Polling سبک یا Refresh زمان‌بندی‌شده استفاده شود.
- برای حذف پیام‌های ۳۰ روزه: python manage.py purge_agency_messages
- فایل‌های ضمیمه قدیمی نیز همراه پیام حذف شوند.
- Audit Log برای اقدامات حساس مثل ارسال گروهی، حذف پیام، تغییر اطلاعیه و مدیریت دانش ثبت شود.
