# راهنمای تولید ویدیوهای آکادمی فایلینگ دیوار

این سند مرجع ساخت **۲۸ ویدیوی آموزشی** آکادمی است. هر ویدیو شامل نام، نام فایل، مسیر ذخیره، مدت هدف و **سناریوی آماده ضبط** (۵ تا ۱۰ خط) است.

---

## قبل از شروع

### مشخصات فنی

| مورد | مقدار |
|------|--------|
| فرمت | MP4 (H.264) |
| رزولوشن | 1920×1080 (حداقل 1280×720) |
| نسبت تصویر | 16:9 |
| فریم‌ریت | 30fps |
| صدا | فارسی، واضح، بدون نویز پس‌زمینه |
| زیرنویس | توصیه می‌شود (SRT جداگانه) |
| پوستر | JPG/PNG — از ادمین «ویدیوهای آکادمی» آپلود کنید (یا دستی در `media/academy/posters/`) |

### مسیر ذخیره فایل‌ها

```
media/
  academy/
    intro/          ← ویدیوهای مسیر آشنایی
    quick_start/    ← شروع سریع + ماموریت روز اول

    crm/            ← مدیریت مشتری

```

### سبک پیشنهادی ضبط

- **لحن:** مربی حرفه‌ای، نه فروشنده — آرام، مطمئن، کاربردی
- **ساختار هر ویدیو:** هوک (۱۰ ثانیه) → مشکل → دمو روی نرم‌افزار → نتیجه → CTA
- **دمو:** موس/لمس را نشان بدهید؛ هر کلیک مهم را ۱–۲ ثانیه مکث دهید
- **متن روی تصویر:** فقط برای نکات کلیدی (۳–۵ کلمه)
- **پایان:** جمله «حالا نوبت شماست» + اشاره به دکمه CTA در آکادمی
