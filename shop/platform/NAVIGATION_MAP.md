## سناریوهای پذیرش

1. گوگل → پیگیری → فهم موقعیت (context bar) → CRM → یادآور → ثبت‌نام/میزکار  
2. Hub امکانات → CRM → یادآور → بازگشت به CRM/امکانات  
3. Hub راه‌حل‌ها → انتخاب مشکل منتشرشده → ابزار یادآور → اقدام نهایی ثبت‌نام/میزکار  
4. Hub امکانات → تحلیل بازار → فایلینگ → ربات → ثبت‌نام/میزکار
